# Optimización de Imágenes - Maplins

## Problemas Identificados

### Header/Navbar
- **Logo principal**: 2626x459px (muy grande para web)
- **Recomendación**: Optimizar a 140px de ancho máximo

### Formas de Pago
- **banner_pagos.webp**: 1916x372px, 183KB
- **registro_vehicular.jpeg**: 1280x271px, 42KB

## Recomendaciones de Optimización

### 1. Logo Navbar
- Tamaño óptimo: 140x25px (manteniendo proporción)
- Formato: PNG con transparencia
- Peso objetivo: < 10KB

### 2. Logo Hero
- Tamaño óptimo: 200x35px
- Formato: PNG con transparencia

### 3. Imágenes de Pago
- **banner_pagos.webp**: Reducir a 800x155px (~50KB)
- **registro_vehicular.jpeg**: Reducir a 600x127px (~15KB)

## Herramientas Recomendadas
- TinyPNG.com (compresión sin pérdida)
- ImageOptim (Mac) o similar
- Photoshop/WebP para conversión moderna
